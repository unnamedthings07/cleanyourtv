# prabhas

Six app tiles in the dock with one more row visible below it (D-pad down scrolls the rest), a frosted dock, a fiery focus glow in each app's colour, five wallpapers that move to the next one every time Home opens, the UNNAMED label above the clock, the full Wi-Fi name in the pill, and the logo splash for about a second on every Home press.

Wallpapers are the owner's own pictures, used as-is; they are not covered by the repo's MIT licence.
`splash`, `wallpaper_on_home`, `brand_text` and `wifi_full_name` need the launcher build from the `prabhas-theme` branch.
